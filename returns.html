Return & Refund Policy

How TOROLAGON handles returns, damaged items, incorrect orders, and refunds.

Last updated: September 28, 2026

Start every return request by emailing info@torolagon.com. Do not mail a product back before receiving return instructions.

Return window

Unopened, unused, factory-sealed products may be eligible for return when the return request is made within 14 days of delivery.

Hygiene and personal-care restriction

Opened, used, tested, sprayed, or unsealed personal-care products are not eligible for standard returns because they cannot be safely returned to saleable inventory.

Damaged, defective, incorrect, or missing items

If your order arrives damaged, defective, incorrect, or missing an item, contact info@torolagon.com. Include your order number, your name, a short description of the issue, and clear photos when applicable. We will review the request and determine the appropriate replacement, refund, or return process.

Approved returns

When a return is approved, TOROLAGON will provide the return instructions directly by email. Customers should not send merchandise to any address that has not been provided for that specific approved return.

Return shipping

For a voluntary approved return, the customer is responsible for return shipping unless TOROLAGON states otherwise. When TOROLAGON shipped an incorrect item or the item arrived damaged or defective, we will provide the appropriate resolution and, when applicable, cover reasonable return or replacement shipping.

Refunds

Approved refunds are issued to the original payment method after the return or claim has been reviewed. Processing time after issuance depends on the payment provider and the customer’s financial institution.

Original shipping charges

Because standard shipping is currently free, there is no standard outbound shipping charge to refund. Any non-standard shipping charges, if offered in the future, may be non-refundable on voluntary returns unless required by law.
